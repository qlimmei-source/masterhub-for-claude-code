# MasterHub: установка и работа

Инструкция для тех, кто делает это впервые. В каждом шаге написано, что набрать и что вы должны увидеть.

**Состояние:** проверено тестами кода модов, у навыков тестов нет. Установка в живом Claude Code пока не прогонялась, поэтому результаты ниже — это то, чего мы ждём по документации.

**Основная система — Windows. Целиком на Mac набор не проверялся: там пробовали только установку и `/hub`** ([раздел о Mac](#10-mac)).

## 1. Что нужно

**Терминал** — это окно, где набирают команды. В Windows нажмите «Пуск», наберите `PowerShell` и нажмите Enter. На Mac откройте программу «Терминал». Чтобы вставить команду в Windows, нажмите в окне правой кнопкой мыши. [Руководство Claude Code по терминалу](https://code.claude.com/docs/en/terminal-guide) показывает это подробнее.

**Claude Code версии 2.1.304 или новее** и платный тариф: в документации сказано, что бесплатный тариф claude.ai не включает Claude Code. Ещё нужен интернет. [Как его установить](https://code.claude.com/docs/en/setup).

Чтобы проверить, наберите в терминале `claude --version`. Вы должны увидеть число вроде `2.1.318 (Claude Code)`. Если число меньше, наберите `claude update`. Если вы пользуетесь только расширением для VS Code, обновите расширение в VS Code.

**Git** — бесплатная программа, через которую Claude Code скачивает набор с GitHub. Аккаунт на GitHub не нужен. [Скачать](https://git-scm.com/downloads). После установки Git закройте окно терминала и откройте новое.

Чтобы проверить, наберите `git --version`. Вы должны увидеть строку вроде `git version 2.41.0.windows.3`.

**Ещё в Windows:**

- Windows 10 версии 1809 или новее: этого требует документация Claude Code.
- Git for Windows, его рекомендует Claude Code. Без него Claude Code выполняет команды через PowerShell.
- Windows PowerShell, он входит в Windows. Им пользуются кнопки **Open folder** и **Show**.
- Команда `code` для кнопки **Open**. Её добавляет установщик VS Code для Windows. Без неё кнопка показывает файл в Проводнике и сообщает об этом.

**Сообщения между чатами.** Главный чат передаёт задачи другим открытым чатам инструментом Claude Code `SendMessage`. В документации сказано, что он включён по умолчанию начиная с версии 2.1.234 в Windows. Чтобы проверить, наберите `/list-agents`. Если команда не распознана, можно ожидать, что помощники в одном чате продолжат работать, а сообщения между отдельными чатами вы будете переносить сами, копированием.

## 2. Установка

MasterHub устанавливается из каталога (в Claude Code он называется marketplace): это список плагинов в одном репозитории. Каталог добавляется один раз, затем из него ставятся плагины.

Выберите способ: только панель VS Code — [В VS Code](#в-vs-code). Claude Code в терминале — [Из терминала](#из-терминала-одна-строка). Git не ставится — [Из ZIP-файла](#без-git-из-zip-файла).

### В VS Code

1. В панели Claude Code наберите `/plugins`. Откроется окно **Manage plugins**.
2. На вкладке **Marketplaces** добавьте `qlimmei-source/masterhub-for-claude-code`.
3. На вкладке **Plugins** найдите `masterhub` и нажмите **Install**.
4. Выберите **Install for you**.

### Из терминала: одна строка

Расширение VS Code не добавляет `claude` в терминал; для этого способа нужен отдельно установленный Claude Code, по ссылке из шага 1.

Мод — это код. Его можно прочитать в папке `plugins/`: примерно 730 строк без тестов.

```
claude plugin install masterhub --marketplace qlimmei-source/masterhub-for-claude-code
```

Вы должны увидеть `Successfully added marketplace: masterhub`, затем `Successfully installed plugin: masterhub@masterhub (scope: user)`.

После этого набор должен быть включён во всех ваших проектах, и в терминале, и в VS Code.

### Внутри Claude Code в терминале

Наберите в чате:

```
/plugin install masterhub --marketplace qlimmei-source/masterhub-for-claude-code
```

Подтвердите добавление каталога. В открывшейся панели выберите **Install for you (user scope)**: установка для вас во всех проектах.

### Без Git: из ZIP-файла

1. На [странице проекта в GitHub](https://github.com/qlimmei-source/masterhub-for-claude-code) нажмите **Code → Download ZIP**.
2. Распакуйте архив в папку, которая останется на месте, например в «Документы».
3. Найдите папку, внутри которой прямо лежит папка `.claude-plugin`. Архив может добавить ещё один уровень папок, поэтому загляните внутрь. Скрытые папки Проводник может не показывать; рядом с ней лежит `README.md`, ищите этот файл.
4. В Claude Code наберите эту команду с путём к той папке. В VS Code введите тот же путь на вкладке **Marketplaces** в окне `/plugins`.

   ```
   /plugin marketplace add C:\путь\к\той\папке
   ```

5. Наберите `/plugin install masterhub@masterhub`. В VS Code используйте вкладку **Plugins**.

Набор будет загружаться из этой папки, поэтому не переносите её. Для новой версии скачайте ZIP заново и замените файлы в этой папке.

## 3. Проверка

Откройте **новый** чат: чаты, открытые до установки, модов не видят.

- **В VS Code:** нажмите `Ctrl+Shift+P`, наберите `Claude Code` и выберите **Open in New Tab**.
- **В терминале:** наберите `/exit`, затем снова `claude`.

Затем:

1. Наберите `/`. В списке должны быть команды под любым из двух имён, коротким или полным: `hub` или `masterhub:hub`, так же `nextchat`, `go`, `ready`, `council`, `interview`, `graphic-design`, `motion`. Ещё в нём должны быть `blocks` и `topic`.
2. Наберите `/blocks` два раза. Первый раз цвета должны выключиться, второй раз включиться и показать подсказку по цветам.

Команд нет в списке? Смотрите раздел [Если что-то пошло не так](#9-если-что-то-пошло-не-так).

## 4. Первый запуск

Папка проекта — это папка на вашем компьютере, где лежит всё для одной работы. Она может быть новой и пустой.

**Откройте в ней Claude Code:**

- **В VS Code:** выберите **File → Open Folder** и укажите папку. Затем нажмите **✻ Claude Code** в правом нижнем углу окна.
- **В терминале:** наберите `cd` и путь к папке, нажмите Enter, затем наберите `claude`.

**Затем:**

1. Введите `/hub` (если не находит — `/masterhub:hub`). Получилось `/рги`? Клавиатура была на русской раскладке: переключите на английскую и наберите снова.
2. Сначала Claude в трёх строках покажет, что такое хаб: этот чат станет главным чатом этого проекта, что изменится в работе, и что у каждого проекта свой главный чат.
3. Claude прочитает ваши собственные правила, если они есть в файлах `CLAUDE.md` в папках выше, и подстроит под них правила проекта.
4. Claude задаст несколько вопросов одной таблицей: темы для проекта (например, Дизайн, Текст, Цены) и лежат ли ваши рабочие файлы в папке вне проекта. Скажите «да» или поправьте.
5. Claude одним шагом создаст папки и правила и скажет, что это значит для вашей работы. Этот чат станет главным и назовётся «MasterHub ВАШПРОЕКТ». Имя должно появиться само.
6. Напишите задачу обычными словами.

Если в папке уже лежит ваша работа, Claude сначала спросит. Он добавит свои папки рядом с вашими и ничего не перенесёт.

## 5. Что делает каждая часть

### `/hub`: главный чат

Один чат принимает все ваши задачи и держит общую картину. Он записывает ваши слова в точности, отдаёт работу помощникам в фоне и показывает вам результаты. Помощник — это отдельный Claude, который делает одну часть работы и отчитывается главному чату. В следующий раз откройте проект и снова наберите `/hub`: он расскажет, что и где стоит.

**Когда:** в начале любого проекта дольше нескольких часов.

### `/nextchat`: переход в новый чат

Длинный чат работает медленнее и тратит больше лимита, то есть того, сколько Claude вы можете использовать по своему тарифу. Команда пишет записку, где остановились, и даёт один блок текста. Откройте новый чат и вставьте блок. Новый чат продолжит по записке. Последняя строка скажет, можно ли закрывать старый чат.

**Когда:** чат стал длинным или Claude начал забывать.

### Утверждение: словами

Готовую вещь вы утверждаете словами про неё: «да», «ок», «отправляй». В журнале `03_FINAL/README.md` её статус становится «утверждено», рядом — ваши слова. После «нормально», «отлично» или выбора одного из вариантов Claude один раз переспросит, утверждаете ли вы. Утверждение никому ничего не отправляет: отправка — отдельное ваше слово.

**Когда:** вы посмотрели готовую вещь в `03_FINAL/` и принимаете её.

### `/go`: все правки одним проходом

Говорите замечания по мере того, как они появляются. Claude записывает их и не трогает файлы. Когда вы скажете `/go`, он внесёт всё разом, соберёт одну новую версию и проверит её. Одну-три мелкие правки он делает сразу, без ожидания.

**Когда:** у вас список правок к чему-то большому.

### `/ready`: как выглядит «готово»

У вас есть общая идея, но нет картинки каждой детали. Claude называет лучшие примеры такой работы, даёт слова, которыми удобно управлять, задаёт только те вопросы, от которых меняется результат, и быстро делает черновик самого важного куска на одном экране. Затем вы получаете короткую карточку: что видно первым, чего не будет, что не трогать.

**Когда:** перед новой страницей, предложением, презентацией или роликом.

### `/council`: проверка критиками

Claude пишет текст, затем его проверяют отдельные критики: например, «Читатель», который стоит на месте вашего настоящего читателя, и «Редактор», который проверяет каждую фразу. Ваши решения остаются такими, как вы сказали. Идея критика, которая меняет смысл, приходит к вам вопросом.

**Когда:** перед любым текстом для других людей. Это тратит дополнительный лимит: тот, кто пишет, и каждый критик работают отдельными помощниками.

### `/interview`: кто вы

Claude задаёт по одному вопросу о вас и вашей работе и сохраняет ответы в папку `about-me/`. Любой чат потом читает их и знает, с кем работает.

### `/graphic-design`: слайды, страницы, обложки

Порядок работы и правила вёрстки в числах: поля, размеры, контраст. Программа проверяет вёрстку до того, как вы её увидите.

### `/motion`: короткие моушн-ролики

Ролики, собранные кодом (HTML и GSAP, рендер в MP4 бесплатным движком HyperFrames). Лист кадров — до сборки, цифры — только ваши, у каждой сцены — оценка.

### `blocks`: цветные плашки

Цветные плашки — это блоки текста с цветным фоном или рамкой. Claude начинает каждый блок со значка, а мод красит блок. Вопрос к вам всегда первым, красной плашкой с рамкой. Пути к файлам становятся строками с кнопками **Open**. Выключить и включить: `/blocks`.

Мод запускает программы только по нажатию его кнопок. [Их список — в README](README.ru.md#что-он-делает-на-вашем-компьютере).

### `chat-topic`: тема под полем ввода

Строка под полем ввода показывает, в каком вы чате. Первая строка сообщения «Чат: Дизайн.» задаёт тему, а `/topic Цены` меняет её. `/hub` должен сам назвать чат «MasterHub ВАШПРОЕКТ». После `/nextchat` старый чат должен стать «OLD MasterHub…», чтобы вы их не путали. Мод читает `CLAUDE.md` вашего проекта и сообщения текущего чата.

### `no-nested-agents`: помощник не запускает помощников

Небольшая программа, которая не даёт помощникам запускать своих помощников. Помощник тогда делает эту часть сам.

### Схема папок

| Папка | Что в ней |
|---|---|
| `00_START_HERE.md` | Карта: где лежит актуальное |
| `01_IN/` | Что пришло снаружи, как пришло. Только читать |
| `02_WORK/` | Работа, по папке на тему |
| `03_FINAL/` | Что уходит наружу, с журналом |
| `04_REF/` | Референсы и ресурсы |
| `08_AGENTS/` | Служебные файлы: задачи, записки для новых чатов, проверки |
| `09_ARCHIVE/`, `_archive/` | Старое. Оно хранится, а не удаляется |

## 6. Обновление

Новая версия сама не придёт, пока вы это не включите.

**В сессии в терминале, включить автообновление (один раз):** наберите `/plugin`, перейдите на вкладку **Marketplaces**, выберите `masterhub`, затем **Enable auto-update**.

**В сессии в терминале, обновить сейчас:** на той же вкладке выберите `masterhub`, затем **Update marketplace**.

**Из терминала, без сессии:** каждая часть набора — отдельный плагин, поэтому на каждую своя строка:

```
claude plugin update masterhub@masterhub
claude plugin update blocks@masterhub
claude plugin update chat-topic@masterhub
claude plugin update no-nested-agents@masterhub
```

Затем наберите `/reload-plugins` в открытом чате или начните новый чат.

**В VS Code:** значок обновления на вкладке **Marketplaces** в окне `/plugins` обновляет список плагинов. Обновление установленного плагина и автообновление руководство по VS Code не описывает. Для них используйте терминал.

Что изменилось, написано в [CHANGELOG](CHANGELOG.md).

## 7. Отключение

**Только цвета:** наберите `/blocks`. Ещё раз — и они вернутся.

**Весь набор, из терминала:** каждая часть набора — отдельный плагин, поэтому нужно четыре строки, в этом порядке. Команды остаются установленными, но не работают, пока вы их снова не включите. Если возвращаться не планируете, [удаление](#8-удаление) проще: одна строка.

```
claude plugin disable masterhub@masterhub
claude plugin disable blocks@masterhub
claude plugin disable chat-topic@masterhub
claude plugin disable no-nested-agents@masterhub
```

Чтобы включить, выполните те же строки со словом `enable`, начиная с `masterhub`.

**В VS Code:** установленные плагины стоят вверху окна `/plugins`, у каждого свой переключатель.

Командам нужны моды, поэтому Claude Code откажется выключить только `chat-topic` или только `no-nested-agents`, пока включён `masterhub`. Он покажет команду, которая выключает оба.

## 8. Удаление

Одна строка в терминале удаляет каталог и все части набора, установленные из него:

```
claude plugin marketplace remove masterhub
```

В сессии в терминале то же самое: `/plugin marketplace remove masterhub`. В VS Code нажмите значок корзины рядом с каталогом на вкладке **Marketplaces** в окне `/plugins`.

Ваши проекты остаются как есть: папки, `CLAUDE.md`, рабочие файлы. Правила в `CLAUDE.md` останутся, пока вы их не поправите.

## 9. Если что-то пошло не так

| Что вы видите | Что сделать |
|---|---|
| `claude` не распознан | В терминале нет Claude Code. Установите его по ссылке из шага 1 или используйте способ для VS Code |
| Ошибка про `git` | Установите Git по ссылке из шага 1, закройте терминал и откройте новый |
| `/hub` нет в списке | Откройте новый чат или наберите `/reload-plugins`. Затем попробуйте полное имя `/masterhub:hub`. С другими командами так же: `/masterhub:go` и так далее. Короткое имя работает, только если на компьютере нет другой команды с именем `hub` |
| Набрали `/hub`, а видно `/рги` | Клавиатура была на русской раскладке. Переключите на английскую и наберите снова |
| `/blocks` или `/topic` нет в списке | Откройте новый чат. В сессии в терминале наберите `/plugin`: строка под вкладками называет загруженные моды |
| Нет цветов | Откройте новый чат. Проверьте версию из шага 1. Наберите `/blocks`, вдруг они выключены |
| Не видна тема | То же самое: новый чат и проверка версии |
| Плагин не загружается | В сессии в терминале наберите `/plugin` и откройте вкладку **Errors** |

**Не помогло?** Скопируйте точный текст ошибки. Покажите его самому Claude в чате или напишите в раздел [Issues проекта на GitHub](https://github.com/qlimmei-source/masterhub-for-claude-code/issues). Официальные инструкции: [установка плагинов](https://code.claude.com/docs/en/plugins/install) и [исправление ошибок](https://code.claude.com/docs/en/plugins/troubleshooting).

## 10. Mac

На Mac тестировщик поставил раннюю версию и настроил проект командой `/hub`. У поля ответа и кнопок `blocks` есть свои команды для Mac (`open`, `code`, `osascript`), на настоящем Mac их ещё не пробовали. Когда **File…** или **Paste screenshot** запустится впервые, macOS может спросить разрешение для редактора: разрешите. Если попробуете, напишите, что получилось, в раздел [Issues проекта](https://github.com/qlimmei-source/masterhub-for-claude-code/issues).
