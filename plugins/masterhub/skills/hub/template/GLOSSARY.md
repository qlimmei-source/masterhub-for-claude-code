## 4. Our chats: for the user only

| Word | What it means |
|---|---|
| MasterHub | the main chat of the project: takes tasks and hands them out |
| hub | the folder `08_AGENTS/HUB/`: a task list for each chat |
| FINAL | the folder `03_FINAL/`: what leaves the project |
| approval | the user's "yes", "ok" or "send it" about a finished thing: its status becomes "approved" |
| `{#tag}` | the fixed address of a section in `CLAUDE.md` or the map: stays the same in every language |
| handoff | a note for a new chat: where things stand |
| `_archive` | the folder for old versions, inside the same folder |
