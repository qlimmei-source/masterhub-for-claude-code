## How files get here · Как сюда попадают файлы {#how}

- A chat puts a **copy** here as soon as its thing is ready to send. Working files stay with the chat.
- A new version sends the previous one to `_archive/` in the same folder. Nothing is deleted.
- Status in the log: "ready, waits for the user" → "approved" → "sent <date>".
- Approval is the user's word about that exact thing: "yes", "ok", "send it". The log keeps those words verbatim. "Nice", "great" or picking an option: ask once, in one line.
